# Web Programming Lab 1 — Band Landing Page

A one-page band website served with Node.js and Express.js (Laboratory Work N1).

## Project structure

```
package.json        project config and dependencies
server.js           Express server (port 3000)
express/
  index.html        page template
  css/styles.css    custom styles (paragraph, li, img, animations)
  js/script.js      JS effects (carousel, modal, button click, form submit, scroll reveal)
```

## Run

```bash
npm install
npm start
```

Then open http://localhost:3000 in your browser.
